# C520 · แก้ไขข้อมูลส่วนตัว

Screen ID: `personaledit` · กลุ่ม: account · screen

[กลับดัชนี](./README.md) · [เหตุการณ์กลาง](./GLOBAL.md)

## ข้อควรตรวจร่วม

- เปิดเคสแล้วตรวจว่าข้อมูล ปุ่ม และปลายทางตรงกับสถานการณ์ ไม่เพียงตรวจข้อความบนหน้าจอ
- ทดลองแก้ข้อผิดพลาดแล้วตรวจว่าผ่านได้ ไม่มี error เก่าค้าง
- กดซ้ำ/ย้อนกลับแล้วไม่สร้างเคส คำสั่งซื้อ หรือบันทึกซ้ำ
- ลองเหตุการณ์กลางขณะกรอก ข้อมูลเดิมต้องยังอยู่
- ผลการปรึกษาและสถานะรายการยาต้องแยกจากกัน

## เคสที่กดทดสอบได้

### EV-C520-normal · แก้ไขข้อมูลส่วนตัว

- รหัสหน้าเดิม: C520.1 · หมวด: สถานะ / การใช้งาน
- เตรียมข้อมูล: เปิดข้อมูลส่วนตัวจากบัญชี
- วิธีทดสอบ: เปิด [เคสนี้](/?screen=personaledit&state=normal&splash=0) หรือกดปุ่มรหัสเดียวกันในแผงขวา จากนั้น กดปุ่มเคส ตรวจข้อมูลและข้อความ แล้วลองแก้ข้อมูลหรือกดปุ่มหลักตามสถานการณ์
- ผลที่ต้องตรวจ: แสดงชื่อ วันเกิด เพศจากข้อมูลสมัคร เบอร์และเลขประชาชนปิดแก้ไข น้ำหนักและส่วนสูงแก้ในสมุดสุขภาพ บันทึกกลับต้นทางโดยไม่เปลี่ยนข้อมูลที่ล็อก
- สถานะ: มี fixture ในต้นแบบ ต้องตรวจผลกับ action และบริการจริงอีกครั้งก่อนส่งมอบ

### EV-C520-invalid · ข้อมูลไม่ครบ

- รหัสหน้าเดิม: C520.2 · หมวด: ข้อผิดพลาด
- เตรียมข้อมูล: เว้นข้อมูลจำเป็นในหน้าแก้ข้อมูลส่วนตัว
- วิธีทดสอบ: เปิด [เคสนี้](/?screen=personaledit&state=invalid&splash=0) หรือกดปุ่มรหัสเดียวกันในแผงขวา จากนั้น กดปุ่มเคส ตรวจข้อมูลและข้อความ แล้วลองแก้ข้อมูลหรือกดปุ่มหลักตามสถานการณ์
- ผลที่ต้องตรวจ: ปุ่มบันทึกยังปิดอยู่ ข้อผิดพลาดอยู่ข้างช่อง และยกเลิกไม่เขียนข้อมูล
- สถานะ: มี fixture ในต้นแบบ ต้องตรวจผลกับ action และบริการจริงอีกครั้งก่อนส่งมอบ
