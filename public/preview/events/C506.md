# C506 · ความยินยอม

Screen ID: `consents` · กลุ่ม: account · screen

[กลับดัชนี](./README.md) · [เหตุการณ์กลาง](./GLOBAL.md)

## ข้อควรตรวจร่วม

- เปิดเคสแล้วตรวจว่าข้อมูล ปุ่ม และปลายทางตรงกับสถานการณ์ ไม่เพียงตรวจข้อความบนหน้าจอ
- ทดลองแก้ข้อผิดพลาดแล้วตรวจว่าผ่านได้ ไม่มี error เก่าค้าง
- กดซ้ำ/ย้อนกลับแล้วไม่สร้างเคส คำสั่งซื้อ หรือบันทึกซ้ำ
- ลองเหตุการณ์กลางขณะกรอก ข้อมูลเดิมต้องยังอยู่
- ผลการปรึกษาและสถานะรายการยาต้องแยกจากกัน

## เคสที่กดทดสอบได้

### EV-C506-normal · อ่านเอกสารความยินยอม

- รหัสหน้าเดิม: C506.1 · หมวด: ความยินยอม
- เตรียมข้อมูล: เปิดสถานการณ์ “อ่านเอกสารความยินยอม”
- วิธีทดสอบ: เปิด [เคสนี้](/?screen=consents&state=normal&splash=0) หรือกดปุ่มรหัสเดียวกันในแผงขวา จากนั้น กดปุ่มเคส ตรวจข้อมูลและข้อความ แล้วลองแก้ข้อมูลหรือกดปุ่มหลักตามสถานการณ์
- ผลที่ต้องตรวจ: การอ่านเอกสารไม่เปลี่ยนความยินยอม ตรวจเงื่อนไขตามบริบทและไม่เลือกให้ผู้ใช้อัตโนมัติ
- สถานะ: มี fixture ในต้นแบบ ต้องตรวจผลกับ action และบริการจริงอีกครั้งก่อนส่งมอบ
