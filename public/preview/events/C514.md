# C514 · สมุดที่อยู่

Screen ID: `addressbook` · กลุ่ม: account · screen

[กลับดัชนี](./README.md) · [เหตุการณ์กลาง](./GLOBAL.md)

## ข้อควรตรวจร่วม

- เปิดเคสแล้วตรวจว่าข้อมูล ปุ่ม และปลายทางตรงกับสถานการณ์ ไม่เพียงตรวจข้อความบนหน้าจอ
- ทดลองแก้ข้อผิดพลาดแล้วตรวจว่าผ่านได้ ไม่มี error เก่าค้าง
- กดซ้ำ/ย้อนกลับแล้วไม่สร้างเคส คำสั่งซื้อ หรือบันทึกซ้ำ
- ลองเหตุการณ์กลางขณะกรอก ข้อมูลเดิมต้องยังอยู่
- ผลการปรึกษาและสถานะรายการยาต้องแยกจากกัน

## เคสที่กดทดสอบได้

### EV-C514-normal · มีที่อยู่หลัก

- รหัสหน้าเดิม: C514.1 · หมวด: สถานะ / การใช้งาน
- เตรียมข้อมูล: เปิดสถานการณ์ “มีที่อยู่หลัก”
- วิธีทดสอบ: เปิด [เคสนี้](/?screen=addressbook&state=normal&splash=0) หรือกดปุ่มรหัสเดียวกันในแผงขวา จากนั้น กดปุ่มเคส ตรวจข้อมูลและข้อความ แล้วลองแก้ข้อมูลหรือกดปุ่มหลักตามสถานการณ์
- ผลที่ต้องตรวจ: แสดง “มีที่อยู่หลัก” ตามเคสจำลอง ตรวจข้อความ ปุ่มที่กดได้ และหน้าปลายทางให้ตรงกับบริบท
- สถานะ: มี fixture ในต้นแบบ ต้องตรวจผลกับ action และบริการจริงอีกครั้งก่อนส่งมอบ

### EV-C514-main-changed · แจ้งเตือน ตั้งเป็นที่อยู่หลักแล้ว

- รหัสหน้าเดิม: C514.5 · หมวด: สถานะ / การใช้งาน
- เตรียมข้อมูล: กดตั้งเป็นที่อยู่หลักบนการ์ดอีกใบ
- วิธีทดสอบ: เปิด [เคสนี้](/?screen=addressbook&state=main-changed&splash=0) หรือกดปุ่มรหัสเดียวกันในแผงขวา จากนั้น กดปุ่มเคส ตรวจข้อมูลและข้อความ แล้วลองแก้ข้อมูลหรือกดปุ่มหลักตามสถานการณ์
- ผลที่ต้องตรวจ: ป้ายที่อยู่หลักย้ายไปการ์ดนั้น และแสดงแจ้งเตือนตั้งเป็นที่อยู่หลักแล้ว
- สถานะ: มี fixture ในต้นแบบ ต้องตรวจผลกับ action และบริการจริงอีกครั้งก่อนส่งมอบ

### EV-C514-address-saved · แจ้งเตือน บันทึกที่อยู่แล้ว

- รหัสหน้าเดิม: C514.6 · หมวด: สถานะ / การใช้งาน
- เตรียมข้อมูล: บันทึกที่อยู่จาก C515 สำเร็จ
- วิธีทดสอบ: เปิด [เคสนี้](/?screen=addressbook&state=address-saved&splash=0) หรือกดปุ่มรหัสเดียวกันในแผงขวา จากนั้น กดปุ่มเคส ตรวจข้อมูลและข้อความ แล้วลองแก้ข้อมูลหรือกดปุ่มหลักตามสถานการณ์
- ผลที่ต้องตรวจ: กลับมาสมุดที่อยู่ และแสดงแจ้งเตือนบันทึกที่อยู่แล้ว
- สถานะ: มี fixture ในต้นแบบ ต้องตรวจผลกับ action และบริการจริงอีกครั้งก่อนส่งมอบ
