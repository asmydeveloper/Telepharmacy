# C210 · เลือกที่อยู่จัดส่ง

Screen ID: `homeaddress` · กลุ่ม: before · sheet

[กลับดัชนี](./README.md) · [เหตุการณ์กลาง](./GLOBAL.md)

## ข้อควรตรวจร่วม

- เปิดเคสแล้วตรวจว่าข้อมูล ปุ่ม และปลายทางตรงกับสถานการณ์ ไม่เพียงตรวจข้อความบนหน้าจอ
- ทดลองแก้ข้อผิดพลาดแล้วตรวจว่าผ่านได้ ไม่มี error เก่าค้าง
- กดซ้ำ/ย้อนกลับแล้วไม่สร้างเคส คำสั่งซื้อ หรือบันทึกซ้ำ
- ลองเหตุการณ์กลางขณะกรอก ข้อมูลเดิมต้องยังอยู่
- ผลการปรึกษาและสถานะรายการยาต้องแยกจากกัน

## เคสที่กดทดสอบได้

### EV-C210-normal · มีที่อยู่

- รหัสหน้าเดิม: C210.1 · หมวด: สถานะ / การใช้งาน
- เตรียมข้อมูล: เปิดสถานการณ์ “มีที่อยู่”
- วิธีทดสอบ: เปิด [เคสนี้](/?screen=homeaddress&state=normal&splash=0) หรือกดปุ่มรหัสเดียวกันในแผงขวา จากนั้น กดปุ่มเคส ตรวจข้อมูลและข้อความ แล้วลองแก้ข้อมูลหรือกดปุ่มหลักตามสถานการณ์
- ผลที่ต้องตรวจ: แสดง “มีที่อยู่” ตามเคสจำลอง ตรวจข้อความ ปุ่มที่กดได้ และหน้าปลายทางให้ตรงกับบริบท
- สถานะ: มี fixture ในต้นแบบ ต้องตรวจผลกับ action และบริการจริงอีกครั้งก่อนส่งมอบ

### EV-C210-empty · ยังไม่มีที่อยู่

- รหัสหน้าเดิม: C210.2 · หมวด: ข้อมูลไม่ครบ / ว่าง
- เตรียมข้อมูล: เปิดสถานการณ์ “ยังไม่มีที่อยู่”
- วิธีทดสอบ: เปิด [เคสนี้](/?screen=homeaddress&state=empty&splash=0) หรือกดปุ่มรหัสเดียวกันในแผงขวา จากนั้น กดปุ่มเคส ตรวจข้อมูลและข้อความ แล้วลองแก้ข้อมูลหรือกดปุ่มหลักตามสถานการณ์
- ผลที่ต้องตรวจ: แสดงข้อมูลว่างหรือรายการที่ขาดอย่างชัดเจน ไม่สร้างข้อมูลแทนผู้ใช้ และตรวจเงื่อนไขปุ่มดำเนินการ
- สถานะ: มี fixture ในต้นแบบ ต้องตรวจผลกับ action และบริการจริงอีกครั้งก่อนส่งมอบ
