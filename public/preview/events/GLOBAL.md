# เหตุการณ์กลาง

[กลับดัชนี](./README.md)

ใช้บนหน้าที่กำลังเปิดอยู่ ไม่กระโดดไปหน้า error อื่น และไม่เปลี่ยน domain state ของแบบร่าง/เคส/คำสั่งซื้อ

## EV-GLOBAL-001 · ไม่มีอินเทอร์เน็ต

- กด: เหตุการณ์กลาง → ไม่มีอินเทอร์เน็ต
- ข้อความ: ไม่มีการเชื่อมต่ออินเทอร์เน็ต — ตรวจสอบสัญญาณแล้วลองอีกครั้ง ข้อมูลที่กรอกยังอยู่
- ผลที่ต้องตรวจ: อยู่หน้าเดิม เก็บแบบร่าง ไม่ส่งคำสั่งขณะจำลองออฟไลน์
- ลองแก้ไขข้อมูลเดิม: ยังพิมพ์ได้ ข้อมูลไม่ถูกล้าง
- ลองกดส่ง/ยืนยัน: ตัวจำลองระงับ data-a/submit และแจ้งว่ายังไม่ได้ส่ง
- ลองใหม่: ยังคงข้อขัดข้อง จนผู้ทดสอบกดจำลองกลับปกติ
- กู้คืน: ปิดเหตุการณ์ ไม่ยืนยัน ไม่ส่ง ไม่ชำระให้อัตโนมัติ
- สำหรับ Flutter: ส่ง fault ผ่าน service adapter; ทดสอบ request ที่ค้าง การ retry และ idempotency เพิ่มเติม ไม่ยก overlay preview ไปใช้เป็นระบบ backend

- ผลที่ต้องตรวจ: แสดงข้อผิดพลาด เก็บข้อมูล ไม่แจ้งว่าบันทึกหรือชำระสำเร็จ

- ลองกดส่ง/ยืนยัน: ตัวจำลองระงับ data-a/submit และแจ้งว่ายังไม่ได้ส่ง

- ผลที่ต้องตรวจ: ไม่สรุปว่าการชำระล้มเหลวหรือสำเร็จ ระบบจริงต้องตรวจผลด้วยรหัสรายการก่อนส่งซ้ำ
