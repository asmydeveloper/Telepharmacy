# C402 · ใบเสร็จรับเงิน

Screen ID: `receipt` · กลุ่ม: after · screen

[กลับดัชนี](./README.md) · [เหตุการณ์กลาง](./GLOBAL.md)

## ข้อควรตรวจร่วม

- เปิดเคสแล้วตรวจว่าข้อมูล ปุ่ม และปลายทางตรงกับสถานการณ์ ไม่เพียงตรวจข้อความบนหน้าจอ
- ทดลองแก้ข้อผิดพลาดแล้วตรวจว่าผ่านได้ ไม่มี error เก่าค้าง
- กดซ้ำ/ย้อนกลับแล้วไม่สร้างเคส คำสั่งซื้อ หรือบันทึกซ้ำ
- ลองเหตุการณ์กลางขณะกรอก ข้อมูลเดิมต้องยังอยู่
- ผลการปรึกษาและสถานะรายการยาต้องแยกจากกัน

## เคสที่กดทดสอบได้

### EV-C402-normal · รับที่ร้าน พร้อมเพย์

- รหัสหน้าเดิม: C402.1 · หมวด: สถานะ / การใช้งาน
- เตรียมข้อมูล: เปิดสถานการณ์ “รับที่ร้าน พร้อมเพย์”
- วิธีทดสอบ: เปิด [เคสนี้](/?screen=receipt&state=normal&splash=0) หรือกดปุ่มรหัสเดียวกันในแผงขวา จากนั้น กดปุ่มเคส ตรวจข้อมูลและข้อความ แล้วลองแก้ข้อมูลหรือกดปุ่มหลักตามสถานการณ์
- ผลที่ต้องตรวจ: แสดง “รับที่ร้าน พร้อมเพย์” ตามเคสจำลอง ตรวจข้อความ ปุ่มที่กดได้ และหน้าปลายทางให้ตรงกับบริบท
- สถานะ: มี fixture ในต้นแบบ ต้องตรวจผลกับ action และบริการจริงอีกครั้งก่อนส่งมอบ
