# C608 · สัญญาณหลุด

Screen ID: `lost` · กลุ่ม: edge · screen

[กลับดัชนี](./README.md) · [เหตุการณ์กลาง](./GLOBAL.md)

## ข้อควรตรวจร่วม

- เปิดเคสแล้วตรวจว่าข้อมูล ปุ่ม และปลายทางตรงกับสถานการณ์ ไม่เพียงตรวจข้อความบนหน้าจอ
- ทดลองแก้ข้อผิดพลาดแล้วตรวจว่าผ่านได้ ไม่มี error เก่าค้าง
- กดซ้ำ/ย้อนกลับแล้วไม่สร้างเคส คำสั่งซื้อ หรือบันทึกซ้ำ
- ลองเหตุการณ์กลางขณะกรอก ข้อมูลเดิมต้องยังอยู่
- ผลการปรึกษาและสถานะรายการยาต้องแยกจากกัน

## เคสที่กดทดสอบได้

### EV-C608-me · เน็ตของคุณหลุด

- รหัสหน้าเดิม: C608.1 · หมวด: การเชื่อมต่อ
- เตรียมข้อมูล: เปิดสถานการณ์ “เน็ตของคุณหลุด”
- วิธีทดสอบ: เปิด [เคสนี้](/?screen=lost&state=me&splash=0) หรือกดปุ่มรหัสเดียวกันในแผงขวา จากนั้น กดปุ่มเคส ตรวจข้อมูลและข้อความ แล้วลองแก้ข้อมูลหรือกดปุ่มหลักตามสถานการณ์
- ผลที่ต้องตรวจ: แจ้งว่าส่งหรือโหลดไม่ได้ เก็บข้อมูลเดิม และให้ลองใหม่เมื่อการเชื่อมต่อกลับมา
- สถานะ: มี fixture ในต้นแบบ ต้องตรวจผลกับ action และบริการจริงอีกครั้งก่อนส่งมอบ

### EV-C608-peer · เภสัชกรหลุด

- รหัสหน้าเดิม: C608.2 · หมวด: สถานะ / การใช้งาน
- เตรียมข้อมูล: เปิดสถานการณ์ “เภสัชกรหลุด”
- วิธีทดสอบ: เปิด [เคสนี้](/?screen=lost&state=peer&splash=0) หรือกดปุ่มรหัสเดียวกันในแผงขวา จากนั้น กดปุ่มเคส ตรวจข้อมูลและข้อความ แล้วลองแก้ข้อมูลหรือกดปุ่มหลักตามสถานการณ์
- ผลที่ต้องตรวจ: แสดง “เภสัชกรหลุด” ตามเคสจำลอง ตรวจข้อความ ปุ่มที่กดได้ และหน้าปลายทางให้ตรงกับบริบท
- สถานะ: มี fixture ในต้นแบบ ต้องตรวจผลกับ action และบริการจริงอีกครั้งก่อนส่งมอบ

### EV-C608-fail · ต่อไม่สำเร็จ

- รหัสหน้าเดิม: C608.3 · หมวด: ข้อผิดพลาด
- เตรียมข้อมูล: เปิดสถานการณ์ “ต่อไม่สำเร็จ”
- วิธีทดสอบ: เปิด [เคสนี้](/?screen=lost&state=fail&splash=0) หรือกดปุ่มรหัสเดียวกันในแผงขวา จากนั้น กดปุ่มเคส ตรวจข้อมูลและข้อความ แล้วลองแก้ข้อมูลหรือกดปุ่มหลักตามสถานการณ์
- ผลที่ต้องตรวจ: แสดงสาเหตุและทางแก้ในบริบทนี้ ไม่แสดงผลสำเร็จ และไม่ล้างข้อมูลที่ยังแก้ต่อได้
- สถานะ: มี fixture ในต้นแบบ ต้องตรวจผลกับ action และบริการจริงอีกครั้งก่อนส่งมอบ
