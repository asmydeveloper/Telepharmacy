# C610 / C611 — research (8 พฤศจิกายน 2569)

Pinterest ต้องล็อกอินและเป็นภาพอย่างเดียว จึงใช้แนวทางที่เผยแพร่จากระบบออกแบบและงานวิจัยแทน

## แหล่งอ้างอิง
- GOV.UK Design System — Service unavailable pages: https://design-system.service.gov.uk/patterns/service-unavailable-pages/
  - ใช้เฉพาะการปิดตามแผน หัวข้อบอกว่าใช้งานไม่ได้ บอกวัน/เวลาที่กลับมา บอกว่าข้อมูลที่กรอกไว้เป็นอย่างไร ช่องทางติดต่อและทางเลือกอื่น ห้ามใช้คำกว้าง ๆ เช่น maintenance/improvements ไม่ใช้ตัวอักษรสีแดง
- GOV.UK Design System — There is a problem with the service pages: https://design-system.service.gov.uk/patterns/problem-with-the-service-pages/
  - ใช้กับปัญหาที่ไม่ได้วางแผน หน้าเดียวทุกสาเหตุ "ลองอีกครั้งภายหลัง" ไม่ใช้ศัพท์เทคนิค/รหัส 500 หรือ "technical difficulties" ถ้าแก้นานให้เปลี่ยนเป็นหน้าปิดให้บริการ
- Nielsen Norman Group — Error-message guidelines: https://www.nngroup.com/articles/error-message-guidelines/
  - ภาษาคนทั่วไป บอกปัญหาเฉพาะ เสนอขั้นตอนถัดไป ไม่โทษผู้ใช้ ไม่ใช้มุก ไม่พึ่งสีอย่างเดียว

## นำมาใช้
| องค์ประกอบ | C610 ปิดตามแผน | C611 ปัญหาไม่คาดคิด |
|---|---|---|
| หัวข้อ | ขออภัย ตอนนี้ยังใช้งานแอปไม่ได้ | ขออภัย ระบบมีปัญหาชั่วคราว |
| เนื้อหา | ปิดตามแผน + วันเวลาที่กลับมา (ตัวอย่าง) + ปรึกษาที่ร้านได้ | ลองอีกครั้งในอีกสักครู่ ไม่ได้เกิดจากเครื่องของคุณ |
| ข้อมูลของผู้ใช้ | ประวัติครบ ยาที่ชำระแล้วร้านดำเนินการตามปกติ | ข้อมูลที่บันทึกไม่หาย คำสั่งซื้อที่ชำระแล้วไม่ต้องชำระซ้ำ |
| ทางเลือก/ติดต่อ | ปรึกษาที่ร้าน + การ์ดติดต่อเรา (ui.callHelp เดียวกับ C601) | เหมือนกัน |
| ปุ่ม | ตรวจสอบอีกครั้ง | ลองอีกครั้ง |

ธีม: ใช้โครงเดียวกับ C601 (halo + ไอคอน หัวข้อกลาง การ์ด kv การ์ดติดต่อ ปุ่มหลักด้านล่าง) และ token เดิม ไม่เพิ่มสีใหม่

## ต่างจากแนวทาง (ตั้งใจ)
- คงกล่องเตือนฉุกเฉิน 1669 สี danger ตามกฎโปรเจกต์ (เรื่องเร่งด่วนใช้ danger) เพราะช่วงนี้ติดต่อเภสัชกรผ่านแอปไม่ได้ ส่วนเนื้อหาหลักไม่ใช้สีแดง

## ต้องยืนยัน
วันเวลาที่กลับมาจากระบบจริง · "คำสั่งซื้อที่ชำระแล้วไม่ต้องชำระซ้ำ" ต้องตรงกับพฤติกรรมระบบชำระเงินจริง · เบอร์และเวลาทำการฝ่ายบริการลูกค้า
- C610/C611 เกลาคำ (8 พ.ย. 2569): ตัดการ์ดข้อมูลและการ์ดติดต่อ เหลือหัวข้อ คำอธิบาย 2 บรรทัด คำเตือนฉุกเฉินสั้น และปุ่ม C610 ไม่แสดงวันเวลา
