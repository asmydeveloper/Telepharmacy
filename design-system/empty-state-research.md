# Contextual empty states

อ่าน Carbon Design System: https://www.carbondesignsystem.com/building-blocks/core/patterns/empty-states (31 ต.ค. 2026)
- ภาพต้องเกี่ยวข้องกับข้อมูลที่ว่าง หัวข้อสั้น และแนะนำสิ่งที่ทำต่อได้
- แยก no data / no results / system error ห้ามสื่อว่าโหลดล้มเหลวคือไม่มีข้อมูล
- ช่องว่างย่อยใช้ภาพเล็ก ลดภาระการอ่าน และภาพ decorative ไม่อ่านซ้ำผ่าน screen reader

การนำมาใช้: สร้าง SVG จากสัญลักษณ์เดิมของแอปในสี CI อ่อน ใช้ `ui.emptyArt(icon)` ร่วมกันทั้งลูกค้าและคอนโซล ภาพ 120×96px ช่องย่อย 80×64px แต่คงข้อความ/ปุ่มของแต่ละหน้าและคำเตือนสุขภาพเดิม ไม่เปลี่ยน unknown allergy เป็น no allergy และไม่แต่งข้อมูลให้สมาชิกใหม่

เคสเดิม: C201 ไม่มีที่อยู่/ไม่พบร้าน/ตรวจสอบพื้นที่ไม่ได้, C210/C514 ไม่มีที่อยู่, C211 ไม่มีร้านโปรด, C401/C402 ไม่พบเอกสาร, C403 ไม่มีประวัติ/ไม่มีผลค้น, C412 ไม่พบยา, C416 ไม่มีรายงาน, C502 ไม่มีสมาชิก, C405 ไม่มีแผน, C408 ไม่มีบันทึก, C404 ไม่มีแจ้งเตือน (รหัสอ้างอิง manifest จริงเป็นหลัก)
