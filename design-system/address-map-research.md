# ตำแหน่งส่งยา — C105, C515, C308
วันที่ 2026-11-02 · ต้นแบบ ยังไม่ได้ทดสอบกับผู้ป่วยจริง

## ข้อกำหนดจากผู้ใช้
- กรอกชื่อ นามสกุล เบอร์ บ้านเลขที่ จังหวัด อำเภอ ตำบล รหัสไปรษณีย์ครบก่อนแสดงแผนที่
- เลือกจังหวัด → อำเภอ → ตำบล เติมรหัสไปรษณีย์อัตโนมัติ
- ขยับหมุดเองได้ แต่ห้ามบันทึกนอกขอบเขตตำบล/แขวงที่ระบุ
- Checkout แสดงข้อความที่อยู่จากหน้าแรกแบบอ่านอย่างเดียว แก้ได้เฉพาะพิกัดของ snapshot เคสนั้น
- ผู้ใช้เลือก “ใช้แผนที่ขยับหมุดเองก่อน” หลังชี้แจงการส่งข้อมูลบ้านเลขที่ไป Google จึงไม่มีการค้นหาบ้านเลขที่กับบริการภายนอกในรุ่นนี้

## หลักฐานและการนำมาใช้
- [W3C Error Identification](https://www.w3.org/WAI/WCAG22/Understanding/error-identification.html): ข้อผิดพลาดต้องมีข้อความอธิบาย ไม่อาศัยสีอย่างเดียว → หมุดแดงพร้อมข้อความ “ระยะไม่สอดคล้องกับที่อยู่ปัจจุบัน…” และปิดปุ่มบันทึก
- [Leaflet 1.9.4](https://leafletjs.com/reference.html): GeoJSON, draggable marker, keyboard events → เลือกด้วยแตะ/ลาก และลูกศรบนแผนที่ได้ โดยแยกการเลื่อนแผนที่กับการยืนยัน
- [OSM Tile Policy](https://operations.osmfoundation.org/policies/tiles/): attribution มองเห็น, HTTPS, ไม่ prefetch, ใช้ HTTP cache ปกติ → คงเครดิตบนแผนที่ โหลดเฉพาะบริเวณที่เปิดดู เปลี่ยน tile provider ได้ผ่าน TP_MAP_TILE_URL; บริการสาธารณะไม่มี SLA
- [กรมป้องกันและบรรเทาสาธารณภัย: DPM_TH_Boundary layer 3](https://gis-portal.disaster.go.th/arcgis/rest/services/MapDX/DPM_TH_Boundary/MapServer/3): Polygon เขตตำบล WGS84, TAM_CODE → query ด้วยรหัสตำบลจากชุดข้อมูลที่อยู่ไทย ผ่าน /api/address-boundary ส่งเฉพาะรหัสเขต ไม่ส่งชื่อผู้รับ โทรศัพท์ บ้านเลขที่

## การตัดสินใจออกแบบ (สมมติฐานที่ต้องทดสอบ)
ใช้ถนนโทนลดสี เส้นเขตประ หมุดสี CI ปุ่มซูมแยก และปุ่มยืนยันใต้แผนที่ เป้าหมายให้แยก “กรอกที่อยู่” กับ “ยืนยันตำแหน่ง” ชัดเจน
ตำแหน่งเริ่มต้นมาจากจุดอ้างอิงตำบล ไม่อ้างว่าเป็นพิกัดบ้าน ผู้ใช้ต้องตรวจสอบและขยับเอง กรณีจุดอ้างอิงอยู่นอกเขตหรืออยู่ในช่องว่างของ polygon จะหาจุดเริ่มต้นภายในขอบเขตแทน ส่วนเคสทดสอบ map-outside จงใจวางหมุดนอกเขตเพื่อทดสอบการบล็อก
โหลดขอบเขตไม่ได้ = ไม่อนุญาตยืนยัน พร้อมปุ่มลองใหม่ ไม่แทนเขตด้วยวงกลมหรือ bounding box

## แก้หมุดไม่ขึ้น / retry 2026-11-02
Static boundary ล้มเหลวจะลอง API ของรหัสเดิมอีกทาง ตรวจ TAM_CODE และ Polygon/MultiPolygon ก่อนใช้; ถ้าทั้งสองทางล้มยังบล็อกบันทึก ไม่ใช้เขตอื่นแทน

## ช่องที่อยู่แยกส่วน 2026-11-02
ตามข้อสรุปผู้ใช้ C105/C515 ใช้ house บ้านเลขที่ (จำเป็น), building หมู่บ้าน/อาคาร/ห้อง/ชั้น (ไม่บังคับ200ตัวอักษร), alley ซอย (ไม่บังคับ100), road ถนน (ไม่บังคับ100) ก่อนจังหวัด อำเภอ ตำบล ไปรษณีย์ รูปแบบเดียวกันทุกหน้าที่แก้ที่อยู่

ยังไม่เชื่อม Geocoding และไม่ส่งที่อยู่ละเอียดออกนอกระบบ การแยกช่องเตรียมข้อมูลสำหรับเชื่อมภายหลัง ไม่อ้างว่าตำแหน่งเริ่มต้นแม่นถึงบ้านแล้ว
