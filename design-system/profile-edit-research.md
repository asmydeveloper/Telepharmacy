# C105 · ข้อมูลส่วนตัวจากบัญชี

ใช้หลักฐาน healthcare forms / plain-language ใน health-record-research.md และฟอร์มสมัครเดิม

ข้อกำหนดล่าสุด 2 พ.ย. 2569: แสดงข้อมูลจาก S.user ที่บันทึกตอนสมัคร ชื่อ นามสกุล วันเกิด และเพศใช้ shared regPersonalFields / date picker กับสมัคร เบอร์/อีเมลและเลขบัตรประชาชนเป็น disabled input ไม่ติด data binding และ save ไม่เขียนทับค่าเหล่านี้ น้ำหนัก/ส่วนสูงแก้ในสมุดสุขภาพ C505 เท่านั้น ไม่แสดงและไม่บังคับกรอกใน personal editor การสมัครใหม่ยังใช้ฟิลด์เดิมตามข้อกำหนดสมัคร

ไม่มีคำอธิบายดอกจันซ้ำด้านบน ใช้ profile-edit-scroll แยกจาก registration-scroll เพื่อไม่เว้นพื้นที่ progress bar ที่ไม่มีในหน้าแก้ข้อมูล

แยกร่าง _profileEdit จาก _registration Date picker รับ target profile-edit ไม่เขียนทับการสมัคร ยกเลิกคงข้อมูล บันทึกเฉพาะชื่อ/นามสกุล/วันเกิด/เพศ ไม่เปลี่ยนสุขภาพ ที่อยู่ ประวัติ หรือ consent ข้อมูลเก่าที่มีแต่ปีไม่เดาเดือน/วันให้ ผู้ใช้เลือกวันที่ครบก่อนบันทึก เลขประชาชนที่ล็อกหรือค่าว่างของข้อมูลสุขภาพไม่ขวางการบันทึก

บัญชีตัวอย่างใน TP.fresh มีข้อมูลส่วนตัวครบสำหรับทดสอบ รวมเลขประชาชนตัวอย่างและวันเกิดเต็ม ไม่เติม fixture ใน render หรือเขียนทับข้อมูลที่ผู้ใช้สมัคร

ทดสอบ tests/profile-edit.cjs รวมสมัครผ่าน registrationService แล้วเปิด afEditProf ยกเลิก/บันทึก การไม่เขียนทับเลขประชาชน/เบอร์/น้ำหนัก/ส่วนสูง และข้อมูลที่ขาดไม่ถูกแทนด้วยตัวอย่าง คง C105 และ suffix เดิม
