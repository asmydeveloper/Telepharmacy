# ปุ่มปรึกษากลางเมนูล่าง — C201 / C203

1 พฤศจิกายน 2569

## หลักฐานที่นำมาใช้
- Material Components: navigation bar รองรับ 3–5 จุดหมาย พร้อมไอคอนและชื่อ https://github.com/material-components/material-components-android/blob/master/docs/components/BottomNavigation.md
- NHS: ปุ่มใช้เริ่มเส้นทางทำรายการ และข้อความต้องสื่อผลของการกด https://service-manual.nhs.uk/design-system/components/buttons

## การตัดสินใจออกแบบ
ปุ่มกลางเป็น action สี primary ชื่อสั้น “ปรึกษา” มีชื่อสำหรับโปรแกรมอ่านจอ “ปรึกษาเภสัชกร” อีกสี่เมนูยังใช้ active pill เดิม กริดและ pill คำนวณเป็นห้าช่อง ไม่เพิ่มความสูงหรือยกปุ่มบังเนื้อหา

เลือกสาขาจากที่อยู่จัดส่งปัจจุบัน ภายในพื้นที่ เปิดรับปรึกษา และมีตัวเลขคิวเป็น 0 ที่ทราบจริง เรียงใกล้ก่อน ไม่ถือคิวที่ไม่ทราบเป็นศูนย์ จากนั้นไปกรอกอาการด้วยรูปแบบสนทนาเริ่มต้น เปลี่ยนวิธีได้ในหน้ากรอกอาการ ไม่เข้าคิวหรือเริ่มโทรแทนผู้ใช้ หากมีเคสค้างกลับเคสเดิม ไม่มีที่อยู่ให้เลือกที่อยู่ ไม่มีร้านว่างเปิดรายการสาขา ระบบปิดใช้ทางเลือกติดต่อเดิม

สถานะและจำนวนคิวขณะนี้เป็นข้อมูลจำลอง ต้องแทนด้วย service ที่ตรวจสถานะปัจจุบันก่อนใช้งานจริง ไม่มีการรับประกันว่าคิวจะยังว่างเมื่อส่งคำขอ ทดสอบ logic ด้วย unit tests; ยังไม่ได้ทดสอบกับคนไข้
