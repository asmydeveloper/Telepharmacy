# ข้อมูลออกใบกำกับภาษี

- [W3C: Labeling Controls](https://www.w3.org/WAI/tutorials/forms/labels/): ใช้ label ที่เชื่อมกับช่องกรอก เพื่อระบุว่าต้องใส่ข้อมูลใด
- [W3C: User Notification](https://www.w3.org/WAI/tutorials/forms/notifications/): แจ้งข้อผิดพลาดใกล้ช่อง พร้อมข้อความบอกวิธีแก้ และแจ้งเมื่อบันทึกสำเร็จ

สมมติฐานการออกแบบ: แยกบุคคลธรรมดาและบริษัท เพื่อแสดงเฉพาะข้อมูลที่เกี่ยวข้อง โดยบันทึกข้อมูลผู้รับแยกจากการส่งคำขอใบกำกับภาษี ยังไม่ได้ทดสอบกับผู้ใช้จริง ต้นแบบไม่มีการออกเอกสารหรือเชื่อมบริการจริง
