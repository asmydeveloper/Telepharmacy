# รหัสเคสและข้อความก่อนปรึกษา — 4 พฤศจิกายน 2026

รหัสแสดงผล caseCode ใช้ MR001 ถึง MR999 แล้ว MR1000 เป็นต้นไป ไม่ตัดหลัก ไม่ใช้เลขลำดับการ์ด จัดเก็บคู่กับ internal case id เดิมเพื่อให้ลิงก์คำสั่งซื้อ ยา รายงาน และใบสรุปไม่เปลี่ยนตามการเรียงรายการ

public/runtime/consultation-data.js เป็นขอบเขต adapter ร่วมของต้นแบบลูกค้าและคอนโซลร้าน มีตารางอ้างอิง fixture เดียวกันและเก็บเลขที่จัดสรรใน browser ขณะสร้างเคส เก็บ note จาก textarea ไว้ใน history และ follow source ณ วันปิดเคส ไม่ใช้ topic สรุปอาการแทนข้อความที่ผู้ใช้พิมพ์ หากข้อมูลเก่าไม่มีข้อความ ให้ระบุว่าไม่มีข้อความอาการที่บันทึกไว้ ข้อมูลจำลองมี note ตัวอย่างแยกใน fixture

รูปแบบ UI: รหัสเคสเป็นหัวข้อ แล้วตามด้วยข้อความต้นฉบับ คงหลายบรรทัดและ escape HTML ใช้การจัดกลุ่มและลำดับชั้นจาก design-system/adr-research.md และ design-system/history-research.md ที่มีอยู่ เป็นการปรับป้ายอ้างอิง/เนื้อหาของการ์ดเดิม ไม่เปลี่ยนข้อมูลทางคลินิกหรือข้อสรุปจากเภสัชกร

ระบบจริงต้องให้ case service ออกรหัสและบันทึกแบบ unique/atomic จากเลขลำดับกลางที่ใช้ร่วมทุกบัญชีและอุปกรณ์ ห้ามใช้ตัวนับใน browser เป็นรหัสระบบจริง เอกสารนี้ไม่ใช่การเชื่อมฐานข้อมูลหรือย้าย schema เดิม ต้นแบบยังไม่ซิงค์เคสที่สร้างใหม่จากแอปลูกค้าไปคอนโซลจริง การค้นรหัสในคอนโซลทดสอบกับรายการ fixture ที่มีอยู่
