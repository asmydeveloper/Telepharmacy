# บัญชีผู้สมัครคนเดียว

คำสั่งผู้ใช้ 2026-11-01: พักส่วนครอบครัวทั้งหมด แอปใช้ข้อมูลเจ้าของบัญชีเท่านั้น

- ไม่สร้างญาติใน mock เริ่มต้น ไม่แสดงเมนูครอบครัว/สมาชิกหรือเลือกคนในหน้าแจ้งอาการ ฝากคำถาม ประวัติ และรายงานอาการหลังใช้ยา
- ประวัติและยาที่เคยได้รับกรองเฉพาะ `who: me` (ข้อมูลเดิมไม่มี who ถือเป็นเจ้าของบัญชีตาม schema เดิม) เก็บข้อมูลสมาชิกเดิมไว้ ไม่เปลี่ยนเจ้าของข้อมูล
- C502, C503, C504 ซ่อนจาก registry/แผงพรีวิวและ /screens และปิดทางเข้าลิงก์เก่า เก็บ implementation และภาพไว้ก่อน
- ถอด states ครอบครัวจาก C203, C605, C403, C412, C413, C416 รหัสหน้าหลักเดิมคงไว้; เลข suffix เคสของหน้าที่ถอดรายการอาจเปลี่ยน ใช้ state slug เป็นตัวอ้างอิง
- หน้า history ใช้หลักจัดกลุ่มและลำดับชั้นเดิมจาก design-system/history-research.md ไม่เพิ่มตัวเลือกผู้รับการปรึกษาที่ไม่จำเป็นในบัญชีเดียว
- การกรองนี้เป็นขอบเขต prototype ฝั่ง UI; เมื่อเชื่อม backend ต้องตรวจสิทธิ์ account owner ที่ API ด้วย
