### C105 · ข้อมูลของคุณและความยินยอม

Screen ID: `profile` · หน้าจอ · อ้างอิงสเปกเดิม C02

**สเปก**

- สมัครใหม่: ข้อมูลส่วนตัว → ที่อยู่ปัจจุบัน → สุขภาพ → ตรวจทานและยินยอม → C108 สมัครสำเร็จ ไม่มีหน้าไม่ยินยอม
- สมัครสำเร็จแล้วตั้งที่อยู่ปัจจุบันเป็นที่อยู่หลัก หน้าแรก C201 จึงมีที่อยู่จัดส่งทันที ต้นแบบใช้ที่อยู่จำลองแทนค่าที่กรอก
- เบอร์โทรยืนยันด้วย SMS OTP ในฟอร์ม (C105.4–.8) อีเมลไม่มีการยืนยันตัวตน สมัครด้วย Google ใช้อีเมลจาก Google แก้ไม่ได้ (C105.3) ผู้สมัครใหม่ตั้งและยืนยันรหัสผ่านในขั้นข้อมูลส่วนตัว
- ข้อมูลสุขภาพแต่ละหมวด (โรคประจำตัว ยาที่ใช้ประจำ แพ้ยา แพ้อาหาร) เลือก ยังไม่ทราบ / ไม่มี / ระบุข้อมูล แล้วพิมพ์ข้อความเอง ไม่มีรายการให้ติ๊ก แนบเอกสารแพ้ยาได้สูงสุด 5 ไฟล์
- ไม่ตั้งค่าไม่มีโรคหรือไม่แพ้ยาให้เอง; ผู้ใช้เลือกยังไม่ทราบได้
- ความยินยอม1ช่องสำหรับบริการเภสัชกรรม ไม่ติ๊กล่วงหน้า เปิดC107อ่านอย่างเดียว ไม่รวมการตลาด; การบันทึกยังเป็นต้นแบบ
- แก้ไขข้อมูลส่วนตัวจากบัญชีย้ายไป C520 แล้ว ไม่มีโหมดบัญชีเว็บเดิม

### C112 · แนะนำแอป

Screen ID: `onboard` · หน้าจอ

**สเปก**

- แนะนำแอป 3 หน้า ใช้การ์ดภาพซ้อนบนพื้นขาวแบบคอลลาจสีมิตรอารี: เภสัชกรที่ตรวจสอบได้ → เลือกสาขาที่พร้อมให้บริการ → ขั้นตอนและข้อจำกัดของการปรึกษา
- มาจากปุ่มเริ่มใช้งานบน C108 หลังสมัครสำเร็จ ปัดซ้ายขวา แตะจุด หรือกดลูกศรบนคีย์บอร์ดได้ ข้ามและเริ่มใช้งานไปหน้าหลัก C201 ถ้าเปิดเคสนี้โดยยังไม่เข้าสู่ระบบจะไป C102
- เวลาและสถานะบริการต้องอิงแต่ละสาขา ไม่มีการฝากคำถามนอกรอบบริการ
- ภาพประกอบเป็นภาพจำลอง ไม่ใช่ตัวตนเภสัชกรหรือการรับรองใบอนุญาตจริง ต้องตรวจข้อมูลผู้ให้คำปรึกษาจากระบบก่อนเริ่มคุย
- ใช้ภาพสื่อสารข้อความหลักควบคู่หัวข้อและคำอธิบายตามแนวทาง CDC Visual Communication ไม่ใส่ข้อความสำคัญไว้เฉพาะในภาพ

**รอเจ้าของเคาะ**

- ให้เภสัชกรผู้รับผิดชอบทบทวนข้อความข้อจำกัดก่อนนำไปใช้จริง

**เหตุการณ์ (3)**

- C112.1 · หน้า 1 เภสัชกรตัวจริง
- C112.2 · หน้า 2 เวลาให้บริการ

### C114 · ลงชื่อเข้าใช้ด้วย Google

Screen ID: `googlelogin` · แผ่นเลื่อนขึ้น

**สเปก**

- เคสเดียว: แตะบัญชีสมาชิกเดิมเข้าหน้าแรก แตะบัญชีสมาชิกใหม่ไปสมัคร C105 กรณีถูกปฏิเสธหรือยกเลิกสิทธิ์ Google แสดงที่ C102.15
- หน้าตาแบบหน้าเลือกบัญชีของ Google: โลโก้ G หัวข้อ เลือกบัญชี ชื่อแอปที่จะเข้าใช้ รายการบัญชี (รูปย่อ ชื่อ อีเมล) และ ใช้บัญชีอื่น พร้อมข้อความว่าจะแชร์ชื่อ อีเมล และรูปโปรไฟล์
- ต้นแบบเท่านั้น ไม่มีการรับรหัสผ่าน Google บัญชีเป็นข้อมูลตัวอย่าง ระบบจริงใช้ Google Identity Services (หน้าเลือกบัญชีของ Google เอง) และตรวจสอบ token ฝั่งเซิร์ฟเวอร์

**เหตุการณ์ (1)**

- C114 · เลือกบัญชี Google: สมาชิกเดิมหรือสมาชิกใหม่

### C115 · ลืมรหัสผ่าน

Screen ID: `forgotpassword` · หน้าจอ

**สเปก**

- หน้าส่งคำขอมีภาพซองจดหมาย ปุ่มส่งอีเมลอีกครั้งพร้อมรอ 60 วินาที และปุ่มกลับไปเข้าสู่ระบบ
- ต้นแบบไม่ส่งอีเมลจริง ระบบจริงใช้ลิงก์ครั้งเดียวที่หมดอายุและตอบข้อความเดียวกันไม่ว่าอีเมลมีบัญชีหรือไม่
- จำไว้ในระบบส่งเป็นตัวเลือก session ให้บริการยืนยันตัวตน ไม่เก็บรหัสผ่านใน browser storage

**เหตุการณ์ (2)**

- C115.1 · กรอกอีเมลเพื่อขอลิงก์ตั้งรหัสผ่าน
- C115.2 · ส่งคำขอตั้งรหัสผ่านแล้ว

## จอผิดปกติ

<a id="c601"></a>
### C601 · บังคับอัปเดตแอป

Screen ID: `update` · หน้าจอ

**สเปก**

- ด่านรุ่นขั้นต่ำ: แอปรุ่นเก่าเรียกคืนไม่ได้ ระบบจึงต้องบังคับอัปเดตได้ · ไม่มีปุ่มปิดหรือย้อนกลับ
- แก้ส่วนปรึกษาเภสัชกร (telepharmacy) ต้องแจ้ง อย. ล่วงหน้า 30 วัน · ด่านนี้ใช้คุมให้ทุกเครื่องใช้รุ่นที่แจ้งไว้แล้ว
- บอกว่าข้อมูลอยู่ครบ เคสที่เปิดอยู่กลับเข้าได้หลังอัปเดต ลดความกังวล

**รอเจ้าของเคาะ**

- มีแบบแนะนำให้อัปเดต (ปิดได้) สำหรับรุ่นที่ยังไม่บังคับด้วยไหม

**เหตุการณ์ (1)**

- C601 · บังคับอัปเดตแอป

<a id="c610"></a>
### C610 · ปิดปรับปรุงระบบ

Screen ID: `maintenance` · หน้าจอ

**สเปก**

- ปิดทั้งแอปชั่วคราวเมื่อระบบปิดปรับปรุงตามแผน ไม่มีปุ่มย้อนกลับ
- บอกว่าข้อมูลและคำสั่งซื้อเดิมอยู่ครบ และให้ไปโรงพยาบาลหรือโทร 1669 เมื่อมีอาการฉุกเฉิน
- ช่วงเวลากลับมาให้บริการต้องมาจากระบบจริง ต้นแบบแสดงเป็นข้อความตัวอย่าง

**รอเจ้าของเคาะ**

- ประกาศเวลาปิดปรับปรุงล่วงหน้าผ่านแจ้งเตือนหรือไม่

**เหตุการณ์ (2)**

- C610.1 · ปิดปรับปรุงระบบ
- C610.2 · กำลังลองเชื่อมต่อ

<a id="c611"></a>
### C611 · เชื่อมต่อระบบไม่ได้

Screen ID: `serverdown` · หน้าจอ

**สเปก**

- ใช้เมื่อเรียก API ใด ๆ ไม่ได้ทั้งระบบ (ต่างจาก C608 ที่สัญญาณหลุดระหว่างวิดีโอคอล และแถบไม่มีอินเทอร์เน็ตของเครื่อง)
- ปุ่มลองอีกครั้งเรียกระบบใหม่ ระหว่างลองปุ่มกดไม่ได้ ไม่มีปุ่มย้อนกลับ
- คงคำเตือนฉุกเฉิน 1669 เพราะผู้ใช้ติดต่อเภสัชกรผ่านแอปไม่ได้

**เหตุการณ์ (2)**

- C611.1 · เชื่อมต่อเซิร์ฟเวอร์ไม่ได้
- C611.2 · กำลังลองเชื่อมต่อ
