# C402 การเลือกใบกำกับภาษี

อ้างอิง W3C APG https://www.w3.org/WAI/ARIA/apg/patterns/switch/ : checkbox เหมาะกับการเลือกข้อมูลสองสถานะ ใช้ label คงที่และ aria-checked พร้อมคำอธิบายที่ผูกกับตัวเลือก ปุ่ม HTML รองรับ keyboard ตามปกติ

สมมติฐานออกแบบ: หัวการ์ดกดได้ทั้งแถว ไอคอนเอกสารสื่อประเภทข้อมูล checkbox อยู่ปลายแถว คำอธิบายอยู่ใต้ชื่อภายในกลุ่มเดียว ลดปุ่มดินสอที่ซ้ำกับการเลือกผู้รับ แสดงเปลี่ยนผู้รับเฉพาะเมื่อมีข้อมูลแล้ว ยังไม่ได้ทดสอบกับผู้ป่วยจริง

## การ์ดการปรึกษาที่ยังดำเนินการ
ใช้หลักการแยกหัวข้อกับข้อความประกอบจาก CDC Visual Communication: https://www.cdc.gov/health-literacy/php/develop-materials/visual-communication.html (หลักฐานที่ใช้ใน onboarding-design.md) นำมาเป็นสมมติฐานจัดหัวสถานะ กลางข้อมูล ท้ายการกระทำ ไอคอนมีข้อความกำกับเสมอ ยังไม่ได้ทดสอบกับผู้ป่วย
